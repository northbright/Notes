# Got "Failed to Playback or Preview" Error in IE Mode of Edge

## Problem
* Added NVR portal as IE mode page in Edge settings > Internet Explorer Pages
* Installed web plugin to use fast-forward function when playback
* Playback and preview worked fine for some days
* Suddenly it could not preview or playback and got "failed to playback" or "failed to preview" error

## Root Cause
* Edge may be upgraded to latest version
* It has problem to playback or preview in IE mode via latest Edge

## Solution
Use Edge mode back.

* Uninstall web-plugin in Control Panel
* Visit NVR in Edge mode
* It can not fast-forward in Edge mode(web-plugin works in IE mode only)
