# Stop Playback First then Drag the Timeline and Start Playback

## Problem
* Select one channel and  start playback via Hikvision web portal
* Drag the timeline to select the time during playback
* The playback time is jumping around

## Solution
* Restart browser or restart PC
* Login Hikvision web portal > Playback > Select one channel > Select date
* A: Stop playback first if it's playing back
* B: Drag the timeline to select the time
* C: Click play to start playback
* Repeat A - C to select another time
