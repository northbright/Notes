# Preview and Playback are OK when Visit Web Portal of New Hikvision NVR via Edge without IE Mode

* It can preview and playback on web portal of new Hikvision NVR(e.g. DS-7808N) via Edge without IE mode(Edge mode)
* Fast-Forward video funciotn requires plugin installed
* The plugin works only in IE mode
* Preview and playback don't work in Edge mode if the plugin is installed
