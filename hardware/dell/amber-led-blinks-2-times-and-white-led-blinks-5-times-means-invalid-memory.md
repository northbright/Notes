# Amber LED Blinks 2 Times and White LED Blinks 5 Times Means Invalid Memory

## Problem
* Dell T3450 failed to boot
* Amber LED Blinks 2 Times and White LED Blinks 5 Times

## Root Cause
* Memory is invalid
* Maybe it needs to clean

## Solution
* Uninstall the memory module(s)
* Use a rubber to clean the memory module
* Install the memory modules(s)
