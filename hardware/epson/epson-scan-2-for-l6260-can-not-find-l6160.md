# Epson Scan 2 for L6260 Can Not Find L6160

## Problem
* EPSON L6268 Printer
* Download and install printer driver and EPSON Scan 2 app for EPSON L6260 series
* Run EPSON Scan 2 and it can not find L6160 series even input IP manually

## Root Cause
* EPSON Scan 2 for L6260 series does not work for L6160 seires

## Solution
* Uninstall EPSON Scan 2 for L6260 series
* Install EPSON Scan 2 for L6160 series
