# Got "missing LC uuid" Error when Run `go test -v ./...` on Latest macOS

## Problem
* A Golang project hosted on Github
* Specify go version to 1.21 and macOS version to "latest" in Github Action

  ```yml
  strategy:
    matrix:
      os:
      - windows-latest
      - macos-latest
      - ubuntu-latest
      go:
      - "1.21"
  ```
* Github Action failed to run `go test -v ./...` on latest macOS
* Got error:

  > dyld[5192]: missing LC_UUID load command in /private/var/folders/XX/T/go-buildXX/xx/1/httputil.test
  > dyld[5192]: missing LC_UUID load command
  > signal: abort trap

## Root Cause
* Old Go(<= 1.22) toolchains lack the cmd/link change that emits `LC_UUID`
* On the current macos-latest image the stricter dyld rejects their test binaries with 'missing LC_UUID load command -> signal: abort trap'

## Solution
* Use new Go version(>= 1.23)
