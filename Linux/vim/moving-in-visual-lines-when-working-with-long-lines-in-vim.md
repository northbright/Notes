# Moving in Visual Lines when Working with Long Lines in Vim

## Problem
* Open a file which contains a large JSON object in ONE line using Vim
* Need to move cursor in VISUAL lines instead of logical lines

## Solution
* Using `gj` / `gk` to moving in visual lines
  * `5gj`: move 5 lines down
