# Click Restore Button but No Response when Restore iPad on mac

## Problem
* iPad Air shows "iPad is not available"
* Connect iPad to MacBook vi USB-C cable
* Press Volume+ then press Volume- and keep pressing power button to enter recovery mode
* Finder on macOS will show iPad
* Click "Restore" button but there's no response

## Root Cause
* It pops up a dialog with message:

  > Need to upgrade the software to continue restoring
* Need to upgrade the software

## Solution
* Click "Upgrade" to upgrade the software
* When upgrade is done, it's ok to restore the iPad

* [如果你无法更新或恢复 iPad](https://support.apple.com/zh-cn/108925)
