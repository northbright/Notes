# Using Email to Create a New Apple Account in China is Preferred

## Problem
* Since iOS 11, it can use mobile phone number to create a new Apple Account on iPhone
* Using email or mobile phone number, which one is better?

## Solution
Using email and binding a mobile phong number is preferred.


* Apple will create an free xx@iCloud.com email address when user uses a mobile phone number to create a new Apple Account
* Email address is useful for resetting password, notifacations...
* More secure if iPhone(SIM) is lost(stolen)
* Need to reset Apple Account when your mobile phone number is changed
